Invisible World
Traffic

A live geographic instrument for seeing aircraft, Washington State Ferries, weather, and atmospheric conditions moving through Western Washington.

What it is

One place, multiple invisible systems.

Invisible World Traffic began as a local ADS-B flight tracker. As more live layers were added, it became a broader view of what is moving through the same geography at the same time: aircraft overhead, ferries crossing Puget Sound, precipitation moving across the region, and current weather conditions at the map center.

The experience is designed for a television at roughly ten feet. Large aircraft silhouettes, altitude masts, hero labels, compact ferry markers, synchronized maps and large-format weather cards make the information legible without turning it into a conventional dashboard.

Aircraft

Live ADS-B positions, speed, heading, barometric altitude, climb/descent state, trails, hero rotation, route enrichment, session records and airport markers.

Washington State Ferries

Selected AIS vessel positions shown as a quiet water layer with directional markers, names, speed, visible/moving counts and session records.

Weather

Looping precipitation radar, current temperature, apparent temperature, wind, gusts, cloud cover and precipitation at the synchronized map center.

Forecast

Large episodic Today and Next 3 Days cards appear briefly, then disappear so Weather remains an ambient live instrument rather than a forecast dashboard.

Synchronized views

Weather and Traffic can run side-by-side. Panning or zooming either map moves the other to the identical geographic view.

Resilient by design

Stale ADS-B data is detected and cleared, route enrichment can fail independently, systemd manages the core services, and the combined view runs as its own persistent service.

Hardware

A Raspberry Pi doing quite a lot.

ComputerRaspberry Pi 5, 4 GB RAM, running Debian Linux as the dedicated lab-pi.
ADS-B receiverAirspy R2 receiving 1090 MHz aircraft broadcasts through an outdoor antenna and coax feed.
Display55-inch TCL television used as the primary 10-foot interface.
Marine dataAIS vessel data collected separately and filtered to the Washington State Ferries fleet for this view.
Camera workloadCrowCam is also running on the same Pi through an RTSP-to-HLS ffmpeg pipeline.

Aircraft ingestairspy_adsb receives ADS-B and feeds readsb, which writes fresh aircraft JSON about once per second.
Traffic UICustom HTML, CSS and JavaScript with Leaflet and OpenStreetMap render aircraft, altitude masts, trails, airports, ferries, hero cards and session stats.
Route enrichmentA Python helper caches route lookups, preserves last-known-good data and hides routes that fail a position/heading plausibility check.
Marine layermarine_live.py collects AIS data, classifies vessels and exposes local JSON; the Traffic UI applies a strict Washington State Ferries fleet filter.
RadarRainViewer recent radar frames are tiled over the Weather map and loop automatically.
Conditions + forecastOpen-Meteo supplies current conditions and daily forecast data at the synchronized map center.
Service managementsystemd manages the ADS-B stack and the persistent combined Weather + Traffic service. Core Traffic runs on port 8090; the combined experience runs separately on port 8097.
